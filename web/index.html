ПРОТОКОЛ

Как передаются команды

05

Видео обслуживает OBS / MediaMTX. Управляющие события идут по WSS через Cloudflare Worker к Windows Host. Worker разрешает только ограниченный набор событий мыши, клавиш и текста; команды запуска произвольных программ не поддерживаются.
